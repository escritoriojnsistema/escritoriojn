# Etapa 17 Implementation Plan

> Execução contínua da especificação do manual; banco delegado e integração conduzida na mesma sessão. Revisão independente ao final.

**Goal:** conectar despesas, transferências e recibos à base financeira existente.
**Architecture:** ampliar RPCs financeiras/ledger privado, API Express tipada e painéis do Caixa; recibo com snapshot persistido.
**Tech Stack:** React + Vite + TypeScript, Express, Supabase PostgreSQL, GitHub → Vercel.
**Spec:** `docs/etapas/etapa-17.md`.

## Global Constraints

- Sem GitHub Actions, deploy CLI/API Vercel, fixtures hospedadas ou concessões individuais automáticas.
- Preservar estornos16, pagamentos15, caixa14 e PDFs históricos.
- Centavos inteiros, transação/locks, autoridade após espera e retry idempotente.
- Padrão Equipe desktop/mobile; até quatro ações principais e sem loaders.

## Review Focus

- Recibo de pagamento pendente ou de outro escritório deve ser negado.
- Transferência simultânea e pagamento de despesa não podem ultrapassar espécie disponível.
- Revogação durante espera e consulta consolidada nunca autorizam operar colega.
- Falha transitória deve manter rascunho e chave estável; conflito exige nova seleção.
- Recibo reimpresso após estorno conserva snapshot original e informa natureza de recebimento original.
