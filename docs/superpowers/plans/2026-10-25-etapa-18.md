# Etapa18 Implementation Plan

**Goal:** fechar caixa com conferência por meio/destino e tratar divergências sem apagar histórico.
**Architecture:** snapshots e decisões append-only sobre o ledger atual; API Express tipada e editor compacto dentro de Caixa. Ajuste de conferência em nova sessão, política RN05 existente; sem entrada/saída fictícia.
**Spec:** `docs/etapas/etapa-18.md`. **Stack:** React + Vite + TypeScript, Express, Supabase, GitHub → Vercel.

## Restrições

- Sem Actions/deployCLI/API Vercel, fixture ou concessão individual hospedada.
- Preservar14–17, ledger único, replay histórico e PDFs1–4.
- Capacidade vigente/escopo/versão após locks; centavos inteiros e comparações exatas.
- Até quatro ações principais, menu lateral e padrão Equipe; sem loaders.

## Revisão

- Sobras/faltas compensadas entre meios não podem ocultar divergência.
- Receita, taxa, liquidação e transferência não podem ser somadas duas vezes.
- Novo fechamento legado não pode contornar conferência digital.
- Aprovação/ajuste nunca concedem operação em sessão alheia nem reescrevem original.
- Fonte histórica/conta desativada ou sessão trocada não reutilizam contagem anterior.
