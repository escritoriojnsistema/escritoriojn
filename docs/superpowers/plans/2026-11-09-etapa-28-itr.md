# Etapa28 Implementation Plan

> **For agentic workers:** Use superpowers:subagent-driven-development to implement and review the tasks.

**Goal:** Controle ITR/DITR por imóvel/exercício/contribuinte integrado ao cadastro rural27 e atendimentos/cobranças existentes.
**Architecture:** RPCs privadas com wrappers invoker, DTO estrito e API Express; seção isolada na tela rural existente. Casos, evidências, calendários e comandos privados com RLS/ACL fechadas.
**Tech Stack:** React/Vite/TypeScript, Express, Supabase PostgreSQL17; GitHub→Vercel.
**Spec:** docs/etapas/etapa-28.md

## Global Constraints

Sem GitHub Actions/deploy direto; sem dados fictícios hospedados ou alteração de permissões anteriores. Sem loaders. Cinco registros por página. Versão esperada e idempotência por sessão. Sem transmissão/aceite oficial ou prazo anual presumido.

## Review Focus

- Original equivalente com outra chave e retificações concorrentes preservam unicidade.
- Perda de acesso/sessão e retry não recuperam dados ou decisões antigos.
- Referências de outro imóvel/ano/contribuinte/atendimento são negadas.
- Honorários pagos não alteram evidências/estado de tributo.
- Calendário exige fonte oficial, conferência e responsável; histórico preservado.
