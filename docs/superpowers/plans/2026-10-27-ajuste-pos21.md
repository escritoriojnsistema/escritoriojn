# Ajuste pós21 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Corrigir acesso e deadlock, cadastrar referências completas adaptadas como rascunhos e publicar com continuidade.

**Architecture:** Preservar Auth e gates20/21, adicionar compatibilidade do navegador e lock ordenado. Minutas usam variáveis manuais declaradas e importação técnica privada com autoria honesta; aprovação continua humana.

**Tech Stack:** React/Vite/TypeScript, Express, Supabase/PostgreSQL17, GitHub→Vercel.

**Spec:** docs/superpowers/specs/2026-10-27-ajuste-pos21.md

## Global Constraints

- Sem GitHub Actions; publicação somente GitHub→Vercel.
- Preservar versões, PDFs históricos, contas, permissões e originais do Drive.
- Até80 variáveis, texto30000/prévia50000, manuais2000 pontos Unicode; tipos text/date/money/number/cpf/cnpj/tax_id.
- Campos `documento.[a-z][a-z0-9_]{0,63}` somente manuais declarados;14 automáticos mantidos.
- Sem loaders, até4 ações, componentes Equipe/mobile e sidebar existentes.
- Rascunhos não aprovados; nunca atribuir importação a um usuário que não atuou.

## Review Focus

- Cancelamento prévio/concorrente deve preservar reason e impedir resposta de outra sessão.
- Fonte financeira automática continua sendo preço do serviço; valores contratuais novos são campos manuais distintos.
- CPF/CNPJ inválidos, campo ausente/removido, Unicode e limite80 devem ter paridade JS/SQL.
- Lote repetido não duplica; falha parcial ou conflito de código reverte o lote inteiro.
- Versão humana anterior/seguinte e documentos capturados continuam imutáveis, aprovação não acompanha nova versão.
