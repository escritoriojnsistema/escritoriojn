Limite80 variáveis/overrides, texto manual até2000 pontos Unicode; entrada legada500 preservada para os14 automáticos, com nomes120 na UI/resolução. CPF/CNPJ validam dígitos no JS/SQL e transportam somente dígitos, máscara incremental na UI. Datas/centavos/extenso/números conservam regras21. Nenhum campo novo consulta automaticamente outra pessoa/ficha. Campo obrigatório removido do texto impede concluir. Texto30000, prévia50000, participantes20 preservados. JSON templates256kb/documentos1mb para UTF8 máximo autorizado. `TemplateVersion.created_by` pode ser null SOMENTE para importação técnica com source_import_id UUID; DTO aceita legado sem source_import_id. UI mostra autoria técnica, política de revisão e nenhuma aprovação implícita.
